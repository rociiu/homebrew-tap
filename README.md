# Homebrew tap

Homebrew only loads casks from taps you trust, so trust the cask first:

```bash
brew trust --cask rociiu/tap/harmune
```

```bash
brew install --cask rociiu/tap/harmune
```

[Harmune](https://github.com/rociiu/harmune) is a keyboard-first Apple Music player for the terminal. It needs macOS 15 or later on Apple silicon, and an Apple Music subscription.
